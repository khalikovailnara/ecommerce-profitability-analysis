# Sales Profitability Analysis (Tableau)
## Project Overview
<img width="1920" height="996" alt="dashboard" src="https://github.com/user-attachments/assets/c642ad6d-cb90-4596-93ef-11e4bcd4d6ce" />


This project presents an interactive Tableau dashboard designed to analyze sales performance and profitability across different product categories and regions.
The goal is to identify low-margin areas, uncover unprofitable segments, and highlight key drivers impacting overall business performance.

## Business Objectives

* Analyze profit margin across product categories
* Identify underperforming and unprofitable segments
* Evaluate regional differences in profitability
* Support data-driven decision-making

## Dashboard Features

* Profit Margin by Category
* Profit Margin by Region
* KPI metrics (Revenue, Profit, Profit Margin)
* Interactive filters (Category, Region, Order Date)
* Heatmap for performance comparison

## Key Insights

* Office Supplies demonstrate the highest profit margin
* Furniture shows significantly lower profitability
* Profitability varies across regions, indicating potential inefficiencies
* Certain segments generate revenue but remain unprofitable

## Tools & Technologies

* Tableau (data visualization)
* SQL (data analysis)

## How to Use

1. Download the `.twbx` file from the `dashboards/` folder
2. Open it in Tableau Public or Tableau Desktop
3. Use filters to explore different segments and regions
